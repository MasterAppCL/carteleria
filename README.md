# Cartelería PNR

Apps de cartelería para Santa Isabel: bajas de precio, captura con foto, ofertas, descuento tarjeta, cartel grande A4, acrílico A4, carteles LPT, cartel exhibición, venta asistida y descriptivos de pizarras.

Abre `index.html` (menú). Se puede instalar y funciona sin internet.
